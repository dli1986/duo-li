## Overview

Twitter/X hosts a growing amount of high-quality technical talks and demos with no native subtitle tracks and no youtube-digest-style extension support. This tool fills that gap for content outside YouTube.

## What it does

1. **Downloads** the video with yt-dlp (no API key required for public tweets)
2. **Transcribes** the audio with Whisper
3. **Analyses** it with the same LLM prompts used by youtube-digest (chapters, key quotes, engineering English terms)
4. **Renders** a self-contained HTML viewer replicating the youtube-digest UI — clickable timestamps, bilingual toggle, notes via localStorage

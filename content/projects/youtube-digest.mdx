## Overview

A customized fork of [zarazhangrui/youtube-digest](https://github.com/zarazhangrui/youtube-digest), kept as a personal working copy for daily use and further tweaks.

## What it does

- Turns captions into a readable, searchable learning resource
- Aligned bilingual view (original transcript + Simplified Chinese translation) for language learning
- AI overview, chapters, key quotes and selected-text explanations
- Click timestamps in the transcript, overview or notes to navigate long videos
- Saves timestamped notes for later study
- Uses your own API keys and local Chrome storage — no analytics, no developer-operated server

# Vision

This site is not a blog.

This site is a long-term personal archive.

Purpose:

- Preserve knowledge
- Preserve projects
- Preserve photography
- Preserve music collections
- Preserve reading history
- Preserve life experiences
- Preserve family memories

The intended lifespan of this project is measured in decades.

The website should remain valuable to:

- Future self
- Family
- Children
- Friends
- Collaborators

The owner controls the content, technology choices and long-term direction.

Success is defined by continuity, not traffic.
